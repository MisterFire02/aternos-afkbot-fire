# 💎 NEBULA AFK CORE v3.0

> Premium Minecraft AFK Bot System with Web Dashboard

## 🚀 Features

### 🤖 Bot Engine
- **Smart Server Connector** - Auto-reconnect with exponential backoff
- **Auto Register/Login** - Intelligent auth detection & human-like delays
- **Human Movement Engine** - Randomized walking, jumping, camera rotation
- **AI Chat Personality** - Context-aware messages with anti-spam protection
- **24/7 Uptime** - Self-healing crash recovery & watchdog monitoring
- **Performance Monitor** - Real-time ping, memory, uptime tracking

### 💰 Premium Dashboard
- **Glassmorphism UI** - Modern luxury design inspired by Tesla & Apple
- **Live Bot Control** - Start, stop, restart with instant feedback
- **Analytics Panel** - Charts, logs, and statistics
- **Behavior Settings** - Adjustable AI personality via sliders
- **Security Features** - Password protection & session tokens
